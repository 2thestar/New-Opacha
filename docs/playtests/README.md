# Playtest evidence

These are scripted games of the actual model, with rendering and sound disabled during the accelerated simulation loop. They are not results from recruited players.

[The original-feel runs](original-feel/) contain the latest zero-start comparisons and fresh-seed tests. [The findings](../original-feel.md) record reference research, controls, shields and haptics. [The expedited runs](expedited/) retain the earlier input and flag-placement comparisons. [The fast playtest guide](../fast-playtest.md) explains the commands. Earlier runs below remain historical evidence.

| File | Games | Purpose |
| --- | ---: | --- |
| campaign.csv | 672 | All 48 maps × seven policies × two decision-error seeds |
| random.csv | 224 | Four modes × four map seeds × two starting seats × seven policies, hard difficulty |
| holdout.csv | 84 | Maps 19, 21 and 48 × four additional error seeds × seven policies |
| bombs-0.5.0.csv | 112 | Version 0.5.0: maps 10, 12, 22, 24, 34, 36, 46 and 48, seven policies, two seeds |
| baseline.csv | 192 | Earlier six-policy diagnostic sweep; policy revisions prevent a causal before/after comparison |

The 980 games in campaign.csv, random.csv and holdout.csv use the version 0.4.0 policy implementation and production rules. Authored maps keep their own difficulty and visible starting forces. Campaign adaptive difficulty is disabled for reproducibility; the shipped adaptive setting can slow the opponents after losses. Extra seeds change decision errors and AI evaluation phase, not the authored geometry.

`HumanStylePlayer.java` defines each strategy and its action limits. `BalancePlaytest.java` writes every match, including eliminated players and unfinished games. `CampaignChecks.java` validates all maps with the real importer and editor model. `TacticsChecks.java` tests prices, combat, regeneration, diplomacy and AI tool decisions.

[Results and reproduction commands](../balance-metrics.md) are generated by `scripts/analyze-playtests.py`. [Interpretation and suggested experiments](../balance.md) distinguish tested mechanics from proposals.

The 112-game version 0.5.0 sweep is a regression check across two later maps in each mode. Its siege policy now uses local bomb supplies and deliveries. It is not a controlled comparison with version 0.4.0 and does not measure human enjoyment. Reproduce with `:lwjgl3:balancePlaytest -PcampaignLab -PlabLevels=10,12,22,24,34,36,46,48 -PlabSeeds=2 -PlabName=bombs-0.5.0` (quote each property argument in PowerShell).
